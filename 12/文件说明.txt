=========================================================
                    多智能体项目文件说明
=========================================================

一、项目概述
------------
本项目是一个基于 LangGraph 的多智能体系统，包含旅行规划、笑话生成、对联创作等功能。

二、文件清单及作用
------------------

1. Director.py
   ┌─────────────────────────────────────────────────────┐
   │ 作用：多智能体核心模块                               │
   │ 功能：                                              │
   │   - 封装了所有智能体节点（supervisor、travel、      │
   │     joke、couplet、other）                         │
   │   - 实现状态图（StateGraph）的构建                  │
   │   - 提供 invoke_graph() 和 stream_graph() 接口     │
   │   - 支持线程ID管理，实现多会话                      │
   │ 调用方式：                                         │
   │   from Director import invoke_graph                │
   │   result = invoke_graph("帮我对个对联")            │
   └─────────────────────────────────────────────────────┘

2. main.py
   ┌─────────────────────────────────────────────────────┐
   │ 作用：FastAPI 后端服务                              │
   │ 功能：                                              │
   │   - 提供 RESTful API 接口（POST /chat）            │
   │   - 支持流式响应（POST /chat/stream）              │
   │   - 静态文件服务（前端页面）                        │
   │   - CORS 跨域支持                                  │
   │ 启动方式：                                         │
   │   python main.py 或 uvicorn main:app               │
   │   访问：http://localhost:8000                      │
   └─────────────────────────────────────────────────────┘

3. 多智能体.py
   ┌─────────────────────────────────────────────────────┐
   │ 作用：原始多智能体框架（开发调试用）                 │
   │ 功能：                                              │
   │   - 包含完整的智能体逻辑                            │
   │   - 可直接运行测试                                  │
   │   - 包含所有节点定义和状态管理                      │
   │ 说明：Director.py 是从这个文件抽取封装的            │
   └─────────────────────────────────────────────────────┘

4. poi_loader.py
   ┌─────────────────────────────────────────────────────┐
   │ 作用：POI 数据加载器                               │
   │ 功能：                                              │
   │   - 从 CSV/JSON 文件加载数据集                      │
   │   - 将数据导入 Redis Hash（poi_data）              │
   │   - 支持向量数据库导入（需 API 可用）              │
   │ 数据来源：                                         │
   │   - C:\Users\Lenovo\couplet_samll\                │
   │   - 包含约 294,072 条对联数据                     │
   └─────────────────────────────────────────────────────┘

5. redis_query.py
   ┌─────────────────────────────────────────────────────┐
   │ 作用：Redis 数据库查询工具                         │
   │ 功能：                                              │
   │   - 测试 Redis 连接                                │
   │   - 统计数据量（HLEN）                             │
   │   - 查询指定数据条目                               │
   │   - 支持关键词搜索                                 │
   │ 使用方式：                                         │
   │   python redis_query.py （交互式查询）             │
   │   或导入使用 from redis_query import RedisQuery   │
   └─────────────────────────────────────────────────────┘

三、目录结构
------------
├── 12/
│   ├── Director.py        # 多智能体核心模块
│   ├── main.py            # FastAPI 后端服务
│   ├── 多智能体.py        # 原始框架（开发用）
│   ├── poi_loader.py      # 数据加载器
│   ├── redis_query.py     # Redis 查询工具
│   ├── 文件说明.txt       # 本说明文件
│   ├── config/            # 配置目录
│   │   ├── __init__.py
│   │   ├── load_key.py    # 密钥加载模块
│   │   └── Keys.json      # API 密钥配置
│   └── static/            # 前端静态文件
│       └── index.html     # 聊天界面

四、智能体功能
--------------
┌─────────────────┬───────────────────────────────────┐
│   智能体名称    │            功能描述                │
├─────────────────┼───────────────────────────────────┤
│ supervisor      │ 分类用户问题，分配给对应智能体     │
│ travel          │ 调用高德 MCP 进行路线规划         │
│ joke            │ 生成幽默笑话                      │
│ couplet         │ 根据上联生成下联（基于 RAG）       │
│ other           │ 处理其他问题                      │
└─────────────────┴───────────────────────────────────┘

五、启动方式
------------
1. 确保 Redis 服务已启动
2. 运行：python main.py
3. 访问：http://localhost:8000

六、测试示例
------------
- 旅行规划："帮我规划从长沙溁湾镇到梅溪湖的路线"
- 笑话："给我讲个笑话"
- 对联："帮我对个对联，上联是：瑞雪兆丰年"
